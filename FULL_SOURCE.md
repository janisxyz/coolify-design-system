https://github.com/coollabsio/architecture/tree/main/design

https://github.com/coollabsio/coolify/blob/main/DESIGN.md

That document is more implementation-specific (Blade components, Livewire morphing notes, unlayered CSS rules) while the architecture one is the clean, portable, Google DESIGN.md format version intended for new React/shadcn stacks.
